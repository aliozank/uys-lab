# Flight Mock Data Generator

Java 17 ile kurallara uygun rastgele uçuş kayıtları üretir ve sonuçları CSV dosyasına yazar.

## Öğrenilen Konular

- Class, object, constructor ve enum
- `List`, döngü, Stream ve lambda
- `Random`, `LocalDate` ve `LocalTime`
- Dosya yazma, `BufferedWriter` ve try-with-resources
- Exception yönetimi
- JUnit ile unit test

## Çalıştırma

`Main` sınıfı çalıştırıldığında 30 uçuş oluşturulur ve `output/flights.csv` dosyasına yazılır.

Testler IntelliJ üzerinden veya Maven `test` lifecycle göreviyle çalıştırılabilir.
